    Projet RED — « Mr Ybot »

    Un jeu de rôle en ligne de commande, écrit en Go, dont l’univers emprunte à la cybersécurité : opérateurs, malwares, pare-feu et monnaie en Ethereum.

    Projet étudiantYmmersion · B1Ynov SophiaLangage GoÉquipe de 3
    Le projet

    Trois semaines pour passer de zéro à un vrai jeu.

    C’est le projet final de l’Ymmersion, la période d’intégration d’Ynov : une piscine Go, un poste de développement configuré, deux jours de Git, puis un sujet commun, le Projet RED, à traiter en équipe.

    L’équipe a gardé les mécaniques demandées par le sujet — personnage, inventaire, marchand, fabrication, combats — et leur a donné un habillage cyber : l’interface, les objets et les ennemis parlent le langage de la sécurité informatique.

    Ma part : le système de combat, les actions, les compétences et les ennemis.

    Trois affiliations

    Choisir son camp, c’est choisir sa résistance.

    Chaque affiliation fixe les points de vie maximum de l’opérateur.

    100 PV

    Anonymous

    L’équilibre : un profil polyvalent.

    80 PV

    LulzSec

    Plus fragile, pour les joueurs qui aiment le risque.

    120 PV

    Lazarus

    Le plus résistant pour encaisser les attaques critiques.

    Les mécaniques

    Ce qui se passe dans le terminal.

    Un opérateur, une affiliation

    Alias vérifié (lettres uniquement), choix parmi trois affiliations cyber, avec des points de vie différents. L’opérateur démarre à moitié de ses PV, avec 100 Ethereum, 3 AntiVirus Patch, la compétence Packet Punch et 10 emplacements d’inventaire.

    Combat au tour par tour

    Face à un « Training Malware » (40 PV, attaque 5), le joueur attaque, utilise une compétence ou fouille son inventaire. L’ennemi suit un schéma : toutes les trois tours, une attaque critique inflige des dégâts doublés.

    Objets et compétences

    Le Corruption Script injecte un poison : 3 fois 10 dégâts, un tick par seconde. Un livre de compétence, Exploit Manual, débloque Zero-Day Blast. L’AntiVirus Patch soigne.

    Marchand et forge

    Un marchand vend des objets en Ethereum ; une forge fabrique des équipements à partir de matériaux : Neural Visor (API Key + Security Token), Firewall Jacket (2 Encrypted Data + 1 Firewall Module), Proxy Boots (1 Encrypted Data + 1 Security Token). Un module étend la capacité d’inventaire.

    Sous le capot

    Un code organisé en modules.

    Chaque domaine du jeu vit dans son propre paquet Go, ce qui permet de se répartir le travail à plusieurs.

    Projet-Red-Mr-Ybot/
├─ main.go
└─ src/
   ├─ character/   personnage, inventaire, équipements
   ├─ combat/      monstres, combats, compétences
   ├─ economy/     marchand, forge
   ├─ items/       objets, prix, recettes
   └─ utils/       menus, dialogues, interface
    Compétences travaillées

    Ce que ce projet apprend.

    • Programmer en Go : structures, packages, tranches, boucles de jeu
    • Concevoir une interface en ligne de commande lisible et immersive
    • Modéliser des règles de jeu : économie, combat, progression
    • Organiser un projet en modules et le versionner avec Git à plusieurs
