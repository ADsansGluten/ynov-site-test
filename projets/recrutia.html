    RecrutIA — « Survie contre le Biais »

    Un mini-jeu de décisions en HTML/CSS : tu incarnes un·e data scientist qui entraîne une IA de tri de CV, et tu découvres comment les données fabriquent le biais.

    Projet étudiantData · B1Ynov SophiaHTML / CSS / JS15 pages
    Le projet

    Apprendre ce qu’est un biais en jouant.

    Réalisé en première année dans la filière Data, ce projet web transforme une notion d’IA en histoire à embranchements : quinze pages, trois fins, deux ambiances visuelles.

    L’idée de l’orienter vers l’entraînement d’un modèle de langage est venue de l’étudiant, avec l’aide de son mentor. Le jeu a été renommé « RecrutIA », du nom de l’entreprise fictive.

    Le principe

    Un jeu en quatre ingrédients.

    Un rôle

    Tu es data scientist chez RecrutIA, une entreprise fictive dont l’IA trie des CV.

    Des décisions

    Au fil de 15 pages connectées, chaque choix sur les données d’entraînement fait évoluer l’IA.

    Trois fins

    Selon tes décisions, le modèle devient équitable, biaisé ou ingérable : trois fins possibles.

    Deux thèmes

    Une version claire avec un bouton jour/nuit, et une version sombre façon « console de données ».

    Compétences travaillées

    Ce que ce projet apprend.

    • Structurer un site en pages HTML connectées par des liens
    • Mettre en forme avec CSS : deux thèmes, composants réutilisables
    • Écrire un petit script JavaScript pour le mode jour/nuit
    • Raconter une notion d’IA — le biais des données — à travers un jeu
    Suite envisagée : une version en Go, jouable dans le terminal.
